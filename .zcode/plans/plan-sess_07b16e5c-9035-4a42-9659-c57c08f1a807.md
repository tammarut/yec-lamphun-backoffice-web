## Decision ledger (source of truth for the resolutions)

### [Layering & client-IP trust strategy](https://github.com/tammarut/yec-lamphun-backoffice-web/issues/121) — resolve & close
- **Origin bypass**: app-authoritative; every control must hold with the edge bypassed. Origin firewall (443 → CF ranges) = deferred follow-up entangled with a CD rework (`--resolve` origin-direct in `cd.yml` would break); CD untouched.
- **L0 (Cloudflare Free)**: the single RL rule (per-IP, 10s/10s) points at `POST /api/v1/members/file/upload` (>3/10s/IP) — contingent on #119 confirming proxied status. BFM stays off (breaks JSON clients). WAF slots spare.
- **Client-IP**: app-level helper in `src/modules/shared/` — `CF-Connecting-IP` only when peer ∈ Cloudflare CIDR list (env-configured), else peer address. Also fixes login's spoofable `x-forwarded-for` first-token read.
- **L2 Traefik**: optional defense-in-depth later only; not required scope (shared instance runs panel + CD path).
- **Prod go-live**: re-create RL rule on prod zone when it exists; helper/origin rulings are domain-agnostic.

### [App-level protection package](https://github.com/tammarut/yec-lamphun-backoffice-web/issues/122) — resolve & close
- **Budgets (per trusted IP, in-memory, "Looser")**: upload 10/10min · renewals POST 20/hour · public reads 120/min · session probe 60/min · **login 5 failures/15min keyed IP+username → 15-min lockout** (default held after explicit offer to double; flag as revisitable). Numbers land in a tunable config object.
- **Placement**: `withPublicGuard(...)` route wrapper (composed like `withAuth` in `src/app/api/middleware/with-auth.ts`) + `@injectable()` RateLimiter behind a new DI symbol token.
- **Origin/Referer gate** (state-changing public routes: login, logout, upload, renewals POST): lenient — present-and-not-allow-listed → `403 { error_message }`; absent headers pass (curl/Apidog/vitest unaffected; kills browser drive-by).
- **Upload pre-parse guard**: `Content-Length` > ~47MB → 413; chunked (no CL) → 411 — **before** `formData()`. (Adopted 413/411 variant, not stream-counting.)
- **429 contract**: `{ error_message }` + `Retry-After` (house-ruled). **Login**: timing-safe compare. **Renewal window**: server-side `open_membership_renewal` check; admin cookie-fork bypasses (ADR-0015); closed → `403 { error_message }`.

### [Turnstile integration design](https://github.com/tammarut/yec-lamphun-backoffice-web/issues/123) — resolve & close
- **Scope (user chose stricter option)**: gates on BOTH slip-upload and renewal submit — widget on dialog open (token for upload) + re-armed widget (`turnstile.reset()`) for submit. Spec must own: token lifecycle, >300s expiry → 403 → Thai copy + re-arm (footer-swap arming lesson applies).
- **Admin fork**: valid `session_id` ⇒ token optional on both endpoints (ADR-0015 pattern).
- **Transport**: multipart field on upload; JSON body field on renewals; both valibot-optional-when-authed.
- **Siteverify**: small `TurnstileService` + DI token, ~5s timeout, **fail-closed split** — invalid/expired/missing token → 403 `{ error_message }`; verify infra unreachable → 503 `{ error_message }` (retryable).
- **Env/CSP**: `TURNSTILE_SITE_KEY` server-injected (t3-env → prop into dialog; client env stays empty, no `NEXT_PUBLIC_*`); secret server-only; CSP += `https://challenges.cloudflare.com` in `script-src` **and** `frame-src` (static string — no new build-arg).
