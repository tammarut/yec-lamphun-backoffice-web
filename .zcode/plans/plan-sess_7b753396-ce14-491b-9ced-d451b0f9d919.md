## SEC-3 (#127): Login lockout throttle + timing-safe compare

### Context
Spec #124 / ticket #127 (SEC-3): admin login must resist brute force. Requirements from the issue: 5 failed logins within 15 min keyed on **trusted IP + username** → 15-min lockout on that pair; attempts during lockout get the 429 contract **even with correct credentials**; successes don't count; compare must be timing-safe (length-normalized); env single-admin model unchanged. SEC-1 (#125) and SEC-2 (#126) are merged, so the trusted-IP helper and origin gate already exist — the issue's "replace first-token XFF read" AC is **already satisfied** by SEC-1 (`login/route.ts:44` uses `resolveTrustedClientIp`); we just verify it, no code change.

### Design
New **auth-module-owned** `LoginLockoutService` (domain-specific, stays in module per AGENTS.md; the shared `RateLimiterService.check()` counts every request — wrong semantics for failure-only counting, so shared limiter untouched):

- `Map<clientKey, { failureCount, windowStartMs, lockedUntilMs }>` where `clientKey = "${ip ?? "unknown"}:${sanitizedUsername}"` (sanitized key prevents lockout bypass via junk-char username padding). Fixed 15-min failure window; 5th failure in window → `lockedUntilMs = now + 15min`. `checkLock()` gates BEFORE compare (so correct passwords are 429'd during lockout); `recordFailure()` on any compare failure; `reset()` on success.
- Time via injected `REGISTER_KEY.WALL_CLOCK` (house pattern); same memory hygiene as the limiter: hard cap + throttled prune of expired entries.
- Lockout error = reuse `RateLimitExceededError` ("Too Many Requests" + `retryAfterSeconds`) → identical 429 contract as `withPublicGuard`: `{ error_message: "Too Many Requests" }` + `Retry-After` seconds.
- Timing-safe compare: module-private helper in `auth.service.ts` — SHA-256 digest both strings (normalizes length, `timingSafeEqual` requires equal lengths), then `node:crypto` `timingSafeEqual`. Applied to username AND password. No dev free-pass on lockout (vitest runs NODE_ENV=test and must exercise it).
